Each icon at 24 px, then its own 16 px drawing, with the word that goes beside it.

  • CloseClose, or Close the menu where two things could close
  • MenuMenu
  • ArrowNext page; mirrored, Previous page; turned up or down, the order a column is sorted in
  • ChevronThe row’s own words; down while closed, up while open
  • DownloadDownload, then the file, its type and its size
  • Another siteAfter a link’s last word, with the hidden words “(another site)”
  • SearchThe field’s label, such as Search the symbols
  • FilterFilters, and how many are on
  • CopyCopy, and what it copies
  • PlayPlay, or Play again once the run has ended
  • PausePause, on the same button while it plays
  • ResetReset or Start over, with its object, such as Reset the loop
  • ErrorError, then the fix, such as Enter a ZIP code with five digits
  • SuccessWhat happened, such as You’re signed up
  • Selected checkA chip’s own word, while the chip is on
  • View full sizeView the map full size
  • SortBeside a column heading’s word
  • WarningWarning, then the notice, such as Warning: Checked April 20
