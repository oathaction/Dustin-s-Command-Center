Forms to avoid, each beside the better choice

Rule 14.57 · A form to avoid

Avoid 3D pies and bars, whose depth bends every value.

Rule 14.73 · A form to avoid

Avoid two value scales on one chart, which can make any two lines cross.

Rule 14.91 · A form to avoid

Avoid gauges, whose angle is harder to read than a bar’s length.

Rule 14.92 · A form to avoid

Avoid thermometers, which spend ink on a tube and a bulb that carry no value.

Forms kept for reference

Rule 14.54 · A reference form

Use a pie only for two or three parts of one whole, with each share printed.

Rule 14.55 · A reference form

Use a donut with a number in its center only when that one number is the point.

Rule 14.56 · A reference form

Use a marimekko when the groups differ in size and each splits into the same parts.

Rule 14.63 · A reference form

Use a violin only for experts, with its box plot drawn inside it.

Rule 14.64 · A reference form

Stack several distributions as a ridgeline only when their order tells the story.

Rule 14.65 · A reference form

Bin very many points into hexagons when a scatter turns to ink.

Rule 14.66 · A reference form

Draw a contour or density only for experts, with its smoothing stated.

Rule 14.70 · A reference form

Use a correlogram only to scan many variables for experts.

Rule 14.71 · A reference form

Use a pair plot to show every pair of a few variables as small scatters.

Rule 14.72 · A reference form

Draw a trajectory to show the pace of change along a path.

Rule 14.78 · A reference form

Show uncertainty as a run of possible outcomes only for experts, with each draw as a still panel.
