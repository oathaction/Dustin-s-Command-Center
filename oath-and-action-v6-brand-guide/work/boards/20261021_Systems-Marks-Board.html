Phase 1 · Systems marks board · for Gate 1 · October 21, 2026

Systems marks for the atlas and the guide

This board proposes the marks that carry evidence, effects, events and authority in every Oath & Action systems graphic. Each section draws the options at true size on Newsprint, White, Charcoal and Prussian, repeats them in grayscale, applies the leading option to a real Atlas V7 example, and closes with a recommendation. The Decisions for Gate 1 panel at the end collects every choice.

Every ID, sign, delay, grade, effect, route and date here was read by script from Atlas V7, snapshot October 15, 2026, on October 21, 2026. The model was not changed. Its inconsistencies go to the atlas editor in work/handoffs/phase-1/20261021_Atlas-V7-1-Issue-List.md.

Tags: Original what a supplied file does today. Defect fix a change that brings a drawing back in line with V7, the model authority. Option a proposal you may accept or decline. Recommended the studio's choice. Misuse a failure the rule prevents.

Mark 1

1. Evidence line code

A connection's line texture shows its evidence grade. V7 sets the code twice, in its methods text and in its renderer: hypothesis dotted, plausible dashed, contested dash-dot, documented and well supported solid. V5 Polished and the Atlas Visual System dash hypotheses and draw every other grade solid, so their key contradicts the model. Concepts V2 already follows V7. Every specimen below is a 2 px line drawn at true size with V7's dash lengths (9 4, 9 3 2 3 and 2 4).

Mark 3

3. Typed ID chips

V7's codes collide, and V7 says so: “Identifiers are exact: R-05 is a reform profile and R5 is a loop, and a code such as B2 can name a variable (local reporting) or a loop (automatic benefits), so the text always says which.” Its renderer adds the type word only when a code is identical across kinds, which covers B2, B3, B4, B5. The script compared every V7 namespace and found 22 codes that match another kind once a hyphen, a leading zero or a letter case is set aside, such as Loop R1 and Reform R-01, Variable D1 and Domain D01, Variable X1 and Issue X01. V5's Standards chapter adds a third R list, rules R1 to R10. The chip below types every code, every time.

Standards rules

V5 numbers its Standards rules R1 to R10, for example R5, “Red is punctuation.”. They become Std-01 to Std-10, cited as “Std-05”. No V7 code starts with Std; its first letter is shared with source IDs such as S05 (prefixes found: S), and the lowercase letters and hyphen keep it apart. G-05 is the fallback with no shared letter (no V7 prefix starts with G).

StandardStd-05

Recommendation

Option B on every surface: the two-part chip with the full type word, and the compact word only where space forces it. Inside a diagram, a code may sit bare where the mark states its kind (a code in a variable box, a code in a connection label on its line) and the key says so. Loops and reforms always carry their type word, in diagrams too. Renumber the Standards rules Std-01 to Std-10. Use “Domain” for D01 to D10; V7's renderer says “Issue area”, which the V7.1 list asks the atlas editor to settle.

Mark 4

4. The ordinal effect mark

V7 gives each reform an expected effect on four outcome families in seven ordinal codes: +L, +M, +S, 0, −S, −M, ?. Of the 200 values, 162 use a plain code and 38 add a qualifier or a range, such as R-06's “+L local” or R-28's “0 to −S”. 6 values on live reforms carry a cost. V7 explains why it never adds them: “The four outcome families use different units. A reform can improve one while imposing a cost on another, and the evidence behind each estimate differs in quality. Keeping the families separate lets readers see those tradeoffs; adding them into one score would hide them.” Concept 10 draws the codes as strand widths in a 1 to 2 to 3 ratio and draws gains only. Concept 11 fills cells by thirds and drops the qualifiers.

Periods: the delivery log

Delivery log dates are text, and V7 lists the cases out of time order. The rule below turns every one of the 24 date strings into a span or a point; the script parsed all of them (0 left over).

  1. Print V7's date text verbatim beside the mark.
  2. Sort and place a period by its start: “1935-1955” sorts at 1935 and runs to the end of 1955.
  3. A year-only period runs from the start of its first year to the end of its last. A month period runs from the first to the last day of its months.
  4. A federal fiscal year runs on the federal calendar: “FY2024” is October 1, 2023 to September 30, 2024.
  5. An open period (“1945-01-25 onward”) runs to the snapshot date, October 15, 2026, with a notch at its end and the word onward in its label.
  6. A date that marks an analysis or a publication (“2024 analysis”, “published 2012”) is a point, drawn as an open square, and never stretches a span.
  7. Never add precision V7 does not state: a year-only date gets no month or day.
