## For Dustin

- **DD10-NF1, ampersand B in a hinge headline (chapters 04 and 05, B locked).** My ruling: in a hinge headline such as "The records law & your answer." B stands for the word "and" in a line a reader must read, so it is text, and WCAG's logotype exception ("text that is part of a logo or brand name") does not reach it; that exception does cover B in the wordmark, the lockmark, the favicon, the avatars and the badge, where B names the brand. Pillar Red on Newsprint measures 2.96 to 1 against 1.4.3's 3 to 1 for large text, short by 0.04, and WCAG does not round. Recommendation: on Newsprint, a hinge headline's B takes Rule 05.3's keyline, the 1 px Charcoal edge drawn inside the mark, which the Understanding page for 1.4.3 counts as the letter's edge (13.29 to 1); on White (4.17), Charcoal (4.49) and Prussian B already passes. This changes how a locked mark is drawn, so it needs Dustin's named approval with B shown at actual size with and without the keyline (CLAUDE.md gate rule 4). The other way, B in the headline's ink on Newsprint, spends no red and needs no keyline, but it changes Rule 04.3's idea of the red moment.
- **E11b-1, `[aria-current]` matching "false" (chapter 18's code set).** Recommend: apply. `c-18-masthead.css` and `c-18-masthead.js` select `[aria-current]`, which matches `aria-current="false"`, the value ARIA defines as "not current" and the one some page builders write on every other link. A partner who copies the code set into such a builder would draw every part as current and open the menu on the first. Change the selectors to `[aria-current]:not([aria-current="false"])`, as `guide_check.js` already reads it. No page writes "false" today, so nothing changes on screen.
- **E11b-2, the first focus ring under the menu's title rule (chapter 18).** Recommend: apply with E11b-1, as one code-set change. The 2 px ring on the menu's first row draws its top side under the title row's 1 px rule (the engineer counted 40 of 40 such stops). WCAG 2.4.11 is met, since the row is never hidden, but the guide's own component is then weaker than the website's, which DR-317 set out to match. A 4 px gap between the title row and the first row fixes it.
