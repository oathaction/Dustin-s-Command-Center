- **Logging owners' calls.** A short script numbered each notes file's "D2-xxx | decision | reason" lines into the log. When a notes file grows after a first logging, skip the lines already logged, and check that the first ones still match. One collision happened when main session lines were appended by hand after the script ran. Always read the last D2 number from the log first.
- **Shared chapter files.** Two makers wrote chapter 12 at once. Rule number ranges were set ahead (D2-829), specimens were named by device rather than by rule, and each maker's script rewrote only its own rules. It worked without conflict.
- **Generator trap.** Chapter files and specimens are written by build scripts: `stage_b_ch10_build.py`, `stage_b_ch12_systems_build.py`, `apply_systems_ch11.py`, the identity scripts, and `guide_editor_ch01.py` with `stage_b_identity_ch01.py` run after it. An edit made only to an output file is lost on the next rebuild. Word changes go into the scripts or their data files.
- **Overlapping rounds.** Starting the editor and chapter 10's maker while the promotion ran, then chapter 11 as soon as chapter 10's construction text existed, saved several hours. Messages to running agents arrive at their next tool call.
