## The craft and accessibility report's items (addendum, calls 15 and 16)

**CA-S2 (call 16), every c-18 set laid out for reading in its panel.** All 24 CSS files and all 24 HTML files are reformatted; nothing they draw or do changed.

- **HTML:** (the rules below are what the files now hold) a start tag longer than 72 characters with two or more attributes puts each attribute on its own line; SVG path data longer than 60 characters breaks only where it already has a space; an inline SVG longer than 72 characters puts each child and its end tag on lines of their own, except inside a status line, an alert, a template or the tracker's update list, where it stays on one line so the words a script or a screen reader takes from that element carry none of its line breaks; table cells take a line each inside their row; a short tag that would carry a line past 100 characters moves its attributes to the next line; prose wraps at its own spaces where no script, check or template reads the words (status and alert lines, buttons, links, labels, cells, templates and the tracker's update list keep their spaces exactly as written). A line break goes only inside a tag, between an SVG's children, between table cells or where a space already stood, so no new space can draw and no new word stands apart.
