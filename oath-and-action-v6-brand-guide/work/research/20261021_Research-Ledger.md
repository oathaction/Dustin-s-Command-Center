# Research Ledger

Oath & Action Brand Guide, Edition 06. Research-to-design ledger for Phase 1, started October 21, 2026 by the research lead. Living ledger: later phases add rows and keep this file's first date. It extends `brief/20261020_Research-Verification-Ledger.md` (Part A to C there) and Master Brief V2 section 5.

## Method and limits

Page fetches fail in this environment. On October 21, 2026, WebFetch on `https://openfontlicense.org/ofl-faq/` returned "getaddrinfo ENOTFOUND", the same block recorded on October 20. So no page in this ledger was opened. Every check below comes from WebSearch run with `allowed_domains` set to the official domain (the award body, the maker, the agency or the license steward), unless a row says otherwise.

Status key:

- VERIFIED: the claim appears in search results from the official domain, consistent across results.
- CORRECTED: verified, with a change to the wording or a fact in the brief.
- PARTLY: part of the claim was confirmed, or it was confirmed only on the maker's own site, or official sources conflict.
- UNVERIFIED: not found on an official domain.

Page read: every row says "Search only". The search tool returns a summary that embeds phrases from the result pages. I mark wording taken from an official-domain result as [snippet]. A [snippet] quote is the best reading available here, and the tool may have paraphrased it, so the guide must check the page before printing it as a quotation.

Every row was checked on October 21, 2026 unless the row says "carried from October 20".

Columns: reference; maker; verified status and date; page read or search only; finding or principle observed; proposed use; limits; URL; date checked.

### What this means for Oath & Action

1. **The current logo.** A wordmark set from Inter Tight outlines and a Lora ampersand is artwork made with OFL fonts. Per L1 to L4, the OFL does not govern that artwork, Oath & Action holds whatever rights the artwork carries, and credit to the font authors is optional. The guide may still credit them in the font credits note that Phase 0 asked for.
2. **What "Lora" as a Reserved Font Name covers.** The reserved name restricts what a Modified Version of the font software may be called (L6, L7). A logo file (SVG, PDF, PNG) holds outlines, so the reserved name does not reach it. Oath & Action may describe the mark as "drawn from Lora Bold" in documentation, because a description that names the original is acceptable where no one could mistake it for the font (L7).
3. **A modified ampersand.** Redrawn as artwork inside the logo, it raises no OFL issue. The issue begins if the studio builds a font file around it: a brand font with the new ampersand, or a Lora subset for the web. That file is a Modified Version. It must stay under the OFL with the original copyright line, ship the license text, and carry a name other than "Lora" (L3, L6, L8). This matches the Phase 0 finding that the Lora subsets in Concepts V1 and V2 keep the reserved name and must not carry into V6.
4. **Inter and Inter Tight.** Their name tables declare no reserved name, so the OFL alone would let a modified copy keep the name. The Inter trademark notice (L10) argues for a new name on any modified build anyway, and for keeping the notice (L9).
5. **Does a drawn, proprietary ampersand strengthen a trademark?** The facts point in one direction, and counsel must confirm it. As a general principle of US practice, which counsel should confirm, trademark rights rest on using a mark to identify a source, and ownership of the font plays no part. The words OATH & ACTION filed in standard characters give the broadest protection (L11), whatever the drawing. A special form registration protects the depiction filed (L11), so a distinctive drawn ampersand gives the stylized mark and any standalone ampersand mark a shape that belongs to Oath & Action alone. The stock Lora glyph is free for anyone to set, so a standalone mark made from it gives others an easy path to a near-identical symbol. That last point is the studio's judgment. Copyright offers little help either way, because the Copyright Office generally refuses lettering and typographic ornamentation (L12). Braver Angels' forced rename in 2020 after a trademark settlement (B12) shows the cost of skipping clearance.

### Where legal advice is needed

A trademark attorney should answer these before launch. I ran no trademark search and give no legal opinion.

- A clearance search for OATH & ACTION, the O&A monogram and any standalone ampersand mark, in the classes that cover publications, newsletters, online information services and educational services.
- Whether to file the words in standard characters, the stylized wordmark in special form, or both, and in which order.
- Whether a standalone ampersand can work as a registrable mark, and how distinctive it must be.
- Whether a drawing derived from Lora Bold outlines needs any further step beyond the OFL position above. The OFL-FAQ says it does not; counsel should confirm for the specific use.
- Foreign filings, if the brand will operate outside the United States.
- Contract terms with any designer or contractor who draws the ampersand, so that Oath & Action owns the drawing.
